## Struttura della Presentazione (12 Slide)

1. **Copertina:** Corso di Programmazione 2, 80 ore di laboratorio, Seconda Annualità.
2. **Il Docente (Daniele Cerrina):** 
   * Formazione: Informatica all'ITIS Pininfarina e Matematica per l'Ingegneria al Politecnico di Torino (PoliTO).
   * Professione: Collaborazione e consulenza con aziende per integrare Web, architetture software e Intelligenza Artificiale nei processi produttivi.
3. **Obiettivo del 2° Anno:** Dallo script isolato al software modulare: progettazione ad oggetti (OOP), gestione di strutture dati organizzate (liste, dizionari) e persistenza delle informazioni su disco.
4. **Python OOP e gli Strumenti del Corso:** Il linguaggio Python con classi e metodi, Visual Studio Code per lo sviluppo multi-file e gestione di file (TXT, JSON) da terminale con `try/except`.
5. **Il Progetto Guida Annuale:** Perché sviluppare un software interattivo a turni per apprendere i pilastri del 2° anno (classi come entità di gioco, liste per inventari/mazzi, file per salvataggi).
6. **Votazione Interattiva:** Scelta d'aula in diretta con widget interattivo tra:
   * **Deck Builder Roguelike:** Carte e strategia a turni con gestione mazzo ed energia.
   * **Trivia Master:** Quiz game show a premi con catalogo domande da file e classifica record.
   * **Vending Machine Manager:** Distributore di esperimenti e compiti di test per modelli IA con report diagnostici.
7. **Routine di Laboratorio:** Scansione standard (0-20 min spiegazione mirata alla lavagna, 20-75 min codice guidato alla postazione, ultimi 15 min correzione collettiva e salvataggio file).
8. **Modalità di Valutazione:** Verifiche scritte (domande a risposta chiusa e aperta con analisi di snippet) integrate da un colloquio orale individuale al PC con modifica estemporanea guidata del codice.
9. **Regole del Laboratorio:** Rispetto delle postazioni hardware, divieto assoluto di copia-incolla cieco, cooperazione costruttiva tra compagni (aiutare a capire, non passare il file pronto).
10. **3 Consigli d'Oro per il 2° Anno:** 
    1. Disegnare la classe su carta prima di scrivere codice (attributi e metodi).
    2. Testare subito ogni metodo con una `print` di verifica.
    3. Leggere il nome del file e il numero di riga nei messaggi di errore di Python.
11. **Il Traguardo Finale:** Le ultime 14 ore per personalizzare il proprio software, collaudo incrociato tra compagni per scovare bug e presentazione finale.
12. **Iniziamo Ora:** Accesso ai computer con credenziali, apertura di Visual Studio Code e creazione del workspace `programmazione_2`.
