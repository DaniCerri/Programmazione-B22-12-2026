Compilato o Interpretato?

Il computer capisce solo numeri. Qualcuno deve tradurre il nostro codice: ma come?

C++ → si compila

descriptionvending.cpp arrow_forward buildcompilatore arrow_forward memoryvending.exe

Come un libro tradotto: prima si traduce tutto, poi si legge. Se c'è un errore anche all'ultima riga, il programma non parte.

Python → si interpreta

descriptionvending.py arrow_forward record_voice_overinterprete arrow_forward play_arrowesecuzione

Come un interprete simultaneo: traduce ed esegue una riga alla volta. Le righe giuste partono, e si ferma alla prima riga sbagliata.

Conseguenza pratica: in Python niente .exe. Lanciamo direttamente il file .py con il comando python nome_file.py.
[6'–9'] Analogia del libro tradotto contro l'interprete alla riunione. Semplificazione onesta: Python in realtà fa anche lui una piccola traduzione interna, ma per noi conta che il file .py si esegue direttamente. Far notare che in Python un errore alla riga 10 non impedisce alle righe 1-9 di essere eseguite: utile per capire gli errori più avanti.

La regola d'oro dell'=

LE REGOLE DEI NOMI

Come Chiamare le Variabili

Un buon nome dice cosa c'è dentro la scatola. In Python si usa lo stile snake_case.

Nomi corretti

  • check_circlecredito minuscolo, chiaro
  • check_circleprezzo_acqua parole unite con _
  • check_circlelattine_vendute si capisce subito
  • check_circlepiano2 numeri sì, ma non all'inizio

Nomi sbagliati

  • cancel2piano inizia con un numero
  • cancelprezzo acqua contiene uno spazio
  • cancelprezzo-acqua il - è il meno!
  • cancelif parola riservata di Python
Maiuscole e minuscole contano: Credito e credito sono due scatole diverse. Evitate gli accenti: quantita, non quantità. E niente nomi da una lettera come x: tra una settimana non vi ricorderete cosa c'era dentro.
[34'–36'] I nomi sbagliati danno errore (tranne gli accenti, che Python accetta ma creano problemi con tastiere e altri programmi: per questo li evitiamo). Il C++ usava spesso camelCase (prezzoAcqua): in Python la convenzione è snake_case (prezzo_acqua).

QUANDO QUALCOSA VA STORTO

Leggere gli Errori (Senza Panico)

Python vi dice cosa non va. Leggete l'ULTIMA riga del messaggio e il numero di riga (line).

Virgolette dimenticate

print(Benvenuto)
NameError: name 'Benvenuto' is not defined
Senza virgolette cerca una variabile che non esiste. Fix: print("Benvenuto")

Maiuscola sbagliata

Print("Ciao")
NameError: name 'Print' is not defined. Did you mean: 'print'?
Python distingue maiuscole e minuscole. Fix: print tutto minuscolo.

Spazio nel nome

prezzo acqua = 1
SyntaxError: invalid syntax
Due parole separate non sono un nome valido. Fix: prezzo_acqua = 1

Testo + numero

print("Totale: " + 5)
TypeError: can only concatenate str (not "int") to str
Il + non unisce testo e numeri. Fix: usate la virgola: print("Totale:", 5)
