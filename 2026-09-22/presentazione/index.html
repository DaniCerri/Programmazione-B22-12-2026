Regole 1 & 2: Finitezza e Definitezza

Due condizioni indispensabili affinché un procedimento sia valido e calcolabile.

hourglass_top
PROPRIETÀ 1

Finitezza

L'esecuzione deve terminare sempre dopo un numero finito di passi.

Se il distributore girasse il motore all'infinito senza fermarsi mai, brucerebbe l'hardware e violerebbe questa proprietà.

Nessun loop infinito
fact_check
PROPRIETÀ 2

Definitezza

Ogni singola istruzione deve essere chiara, univoca e senza dubbi.

Non possiamo dire a una macchina "eroga un po' di caffè": dobbiamo ordinare "apri l'elettrovalvola per 30 ml d'acqua".

Comandi deterministici
Chiedere: perché un umano capisce 'versa un filo d'olio' ma un computer no? Perché l'umano usa il contesto e l'esperienza, la macchina solo logica binaria.

L'Operatore Modulo (%): Il Resto della Divisione

Calcola l'avanzo di una divisione intera tra due numeri.

Operatore OR (||): Basta Almeno una Vera

CASI COMPLESSI

Espressioni Booleane Composte e Parentesi

Come combinare controlli multipli stabilendo l'ordine corretto con le parentesi tonde.

Pagamento con Monete o Tessera

Acquisto Valido

// Parentesi tonde per unire i pagamenti: SE ( (credito >= PREZZO O chiavetta_valida) E scorte_disponibili > 0 ) { eroga_prodotto(); }

L'utente può pagare con contanti OPPURE chiavetta ricaricabile, ma in entrambi i casi serve che ci siano scorte!

Priorità degli Operatori

L'Importanza delle Parentesi

In logica, l'operatore AND ha la precedenza su OR (proprio come la moltiplicazione ha la precedenza sull'addizione in matematica!).

Usare le parentesi tonde garantisce che il computer interpreti il raggruppamento esatto desiderato.

Scrivere alla LIM: A || B && C. Senza parentesi viene interpretato come A || (B && C). Con le parentesi (A || B) && C il significato cambia completamente!

CONTROLLO DI FLUSSO

La Struttura di Selezione Bivalente: IF - ELSE

Il bivio a due vie: se la condizione è vera fai A, altrimenti fai B.

SE (credito >= PREZZO_SNACK) { mostra("Snack erogato! Ritira il prodotto."); credito = credito - PREZZO_SNACK; eroga_resto(credito); } ALTRIMENTI { mancano = PREZZO_SNACK - credito; mostra("Credito insufficiente!"); }
Concetto Fondamentale
  • check Esclusione reciproca: viene eseguito SOLO uno dei due rami, mai entrambi!
  • check Else universale: l'altrimenti raccoglie tutti i casi in cui la condizione iniziale non è soddisfatta.
Nel diagramma di flusso questo è il rombo di decisione: da un lato esce la freccia VERO, dall'altro la freccia FALSO.

CONTROLLO DI FLUSSO

Scelte Multiple a Cascata: Decodificare i Tasti

Quando le alternative possibili sono molteplici: valutazione ordinata a esclusione.

SE (codice == "A1") { prodotto = "Caffè Espresso"; } ALTRIMENTI SE (codice == "A2") { prodotto = "Cappuccino"; } ALTRIMENTI SE (codice == "B1") { prodotto = "Acqua Naturale"; } ALTRIMENTI { prodotto = "Codice errato!"; }
Come Funziona la Cascata?

1. Il computer controlla la prima condizione.
2. Se è falsa, scende alla seconda.
3. Appena ne trova una VERA, esegue il suo blocco ed ESCE subito dalla cascata!
4. L'altrimenti finale intercetta i codici digitati per sbaglio.

In C++ potevano usare anche lo switch-case. Far notare che la logica di 'scelta multipla a esclusione' è la medesima.

PILASTRO 4: CICLI

Perché Ripetere? I Cicli e il Principio DRY

Don't Repeat Yourself: non riscrivere a mano istruzioni ripetitive.

SBAGLIATO

Copia & Incolla a Mano

testa_motore_slot(1); testa_motore_slot(2); testa_motore_slot(3); // ... riscrivere 50 righe a mano!
CORRETTO (DRY)

Usare una Struttura Iterativa

Il principio DRY è uno dei fondamenti dell'ingegneria del software. La macchina ripete senza stancarsi e senza sbagliare.

Il Ciclo Pre-Condizionale (WHILE / FINCHÉ)

PERICOLO CRASH

Allarme Loop Infinito: La Macchina si Blocca!

Cosa accade se la variabile di controllo non viene mai aggiornata.

sync_problem

Il Loop Senza Fine

credito = 0.00; MENTRE (credito < 1.50) { mostra("Inserisci moneta..."); // ERRORE: non aggiorniamo mai credito! }

credito rimarrà 0.00 in eterno. La condizione sarà vera per sempre e la macchina impegnerà il 100% della CPU senza mai uscire.

All'interno del corpo di un ciclo WHILE deve sempre esistere un'istruzione che modifica la variabile di test per avvicinarsi alla condizione di uscita!

Nel terminale di sviluppo il tasto di arresto forzato è sempre Ctrl+C.

I 3 Elementi del FOR

In qualsiasi linguaggio un ciclo FOR gestisce tre cose:

1. Inizializzazione: da dove parte il contatore.
2. Condizione di fine: fino a che numero contare.
3. Passo: di quanto aumenta a ogni giro (di solito +1).

In C++ scrivevano: for (int i = 1; i <= 3; i++). Mostrare che i 3 elementi sono identici concettualmente.

Confronto Concettuale: Quando Usare WHILE o FOR?

Come selezionare la struttura iterativa corretta in base al problema.

Usa WHILE quando:
  • • Non sai prima quante volte ripeterai.
  • • Dipende dall'utente (es. "chiedi monete finché il credito non basta").
  • • Dipende da un sensore fisico (es. "gira finché la fotocellula non rileva la caduta").
Usa FOR quando:
  • • Sai in anticipo quanti passi compiere (es. "fai 3 rotazioni").
  • • Vuoi scorrere tutti gli elementi di una lista o vettore.
  • • Vuoi contare numericamente da un inizio a una fine.
Fare un quiz: per verificare tutti i 6 ripiani del distributore? (FOR). Per aspettare che l'utente inserisca il PIN segreto? (WHILE).

Vettori (Array): La Regola Sacra dell'Indice da ZERO

Una sequenza contigua di celle in memoria dello stesso tipo, ordinate per posizione.

Perché si Parte da Zero?

In informatica l'indice è un offset (distanza dall'inizio della prima cella di memoria):

vetrina = ["Patatine", "Cioccolato", "Biscotti"]; vetrina[0] // "Patatine" (Distanza 0: PRIMO elemento!) vetrina[1] // "Cioccolato" (SECONDO elemento) vetrina[2] // "Biscotti" (TERZO elemento)
warning

Accesso Fuori Scala!

Se il vettore ha N = 3 elementi, gli indici validi sono 0, 1 e 2.

Cercare l'indice [3] provoca un errore di memoria (Out of Bounds / Segmentation Fault)! L'ultimo indice è sempre N - 1.

In C++ l'indice è aritmetica dei puntatori: *(vetrina + 0) è la prima cella. Ecco perché TUTTI i linguaggi moderni partono da 0!

SCORRIMENTO DATI

Scorrere un Vettore: L'Unione di FOR e Array

Il pattern universale per visitare uno a uno tutti gli elementi di una collezione.

Scorrimento per Indice (da 0 a N-1)
bevande = ["Espresso", "Ginseng", "Tè"]; N = 3; PER i DA 0 A (N - 1): mostra("Posizione " + i + ": " + bevande[i]);

La variabile i fa da puntatore mobile da 0 fino all'ultimo elemento.

Cosa Fa Fisicamente il Computer?

Giro 0: legge la cella 0 → "Espresso"
Giro 1: legge la cella 1 → "Ginseng"
Giro 2: legge la cella 2 → "Tè"
Fine: esce dal ciclo senza toccare memorie esterne!

Questo algoritmo di scansione lineare è la base di qualsiasi ricerca, ordinamento o visualizzazione di dati.

STRUTTURE DATI

Le Stringhe: Vettori di Caratteri

Una parola o un codice alfanumerico è una sequenza ordinata di singoli simboli.

Scomporre il Codice Tastiera

Possiamo accedere ai singoli caratteri tramite il loro indice:

codice = "B2"; lettera_corsia = codice[0]; // 'B' (primo carattere) numero_spirale = codice[1]; // '2' (secondo carattere)

Proprietà delle Stringhe

  • • Lunghezza: il numero totale di caratteri del testo.
  • • Concatenazione (+): unione di due testi in un unico messaggio.
  • • In C++ era char[] o std::string: in tutti i linguaggi l'accesso posizionale avviene con le parentesi quadre [ ].
Ricordare che in memoria ogni carattere corrisponde a un codice numerico della tabella ASCII (es. 'A' è 65).

Trova il Bug Logico nel Controllo!

Chi sa individuare l'errore concettuale in questo frammento?

Codice Proposto
moneta = 1.00; SE (moneta = 1.00) { credito = credito + moneta; }
Bug Logico: Assegnazione invece di Confronto!
È stato usato il singolo = (che scrive nella memoria) al posto del doppio == di confronto!
La riga corretta è: SE (moneta == 1.00)
Chiamare uno studente alla lavagna a cerchiare il singolo uguale.

SFIDA ALLA LIM (2/3)

Trova il Bug Logico nel Ciclo!

Perché questo algoritmo non uscirà mai dal ciclo?

Codice Proposto
credito = 0.00; PREZZO = 1.50; MENTRE (credito < PREZZO) { mostra("Inserisci moneta da 50 cent..."); }
Bug Logico: Mancata Modifica della Variabile di Controllo!
All'interno del blocco manca l'istruzione di avanzamento: credito = credito + 0.50;.
Senza questa riga, la condizione 0.00 < 1.50 sarà vera all'infinito!
La causa di tutti i loop infiniti: dimenticarsi di cambiare il valore della variabile testata nella condizione.

SFIDA ALLA LIM (3/3)

Trova il Bug Logico nell'Accesso al Vettore!

Perché questa istruzione causa un errore fatale di memoria?

Codice Proposto
prodotti = ["Patatine", "Cioccolato"]; // Vettore di 2 elementi scelta = 2; mostra("Erogazione: " + prodotti[scelta]);
Bug Logico: Violazione dei Limiti del Vettore (Out of Bounds)!
Il vettore ha dimensione 2: gli indici ammessi sono 0 (primo) e 1 (secondo).
L'indice 2 punta a una cella di memoria non assegnata e manda in crash il programma!
Ricordare che in C++ questo può causare undefined behavior o crash di memoria (Segmentation Fault).

ESERCIZIO GUIDATO

Modellare il Vending Machine: 2. L'Algoritmo di Vendita

Controllo di sicurezza con IF, erogazione e calcolo rigoroso del resto.

// Condizione: il credito basta E ci sono prodotti disponibili? SE (credito_inserito >= PREZZO_SNACK E scorte_rimaste > 0) { mostra("Erogazione prodotto in corso..."); scorte_rimaste = scorte_rimaste - 1; resto = credito_inserito - PREZZO_SNACK; mostra("Resto erogato: " + resto + " euro"); credito_inserito = 0.00; } ALTRIMENTI { mostra("Acquisto impossibile: credito insufficiente o prodotto esaurito!"); }
In sole 10 righe ci sono tutti i pilastri: variabili, costanti, operatori aritmetici, confronto >=, operatore logico E, selezione IF-ELSE.
